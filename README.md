# Resume Generator

一个简单的想法：**做简历这事，你把经历说出来，剩下的交给 AI 和一个网页模板。**【可以吧照片提前放好】

你跟 AI 说"帮我做份简历"，它就知道你当什么工作、有什么经历，然后把内容塞进预设好的模板里，你浏览器打开直接打印 PDF。

换内容？重新跟 AI 说就行。换风格？换套 CSS 的事。

更绝的是看上了别人的排版——截图发给 AI，它照着样子给你配一套新的样式。设计灵感不用从零开始。

---

## 干嘛要有这些约束

不是限制你，是在帮你省时间。

- **就一页 A4**：不打分页，不溢出。内容多了自动压缩，字号保底 11px，挤不死
- **左边放个人信息，右边放经历**：顺序固定，不用纠结排版
- **颜色已经配好了**：深蓝打底 + 白纸黑字，不用你做设计决策

有这些边框着，**只要你说清楚经历，出来的东西就是一张能用的简历。** 没有选模板选字体调间距这种破事。

---

## 怎么玩

**最省事**：跟 AI 说你要份简历，把经历讲一遍，它帮你搞定。打开浏览器打印就行。

**换个风格**：告诉 AI 换个配色或字体，它改 CSS，结构不动。

**从零做新模板**：告诉 AI 你想要什么样的布局，它会生成新的 HTML 骨架。

**最骚的操作**：看到喜欢的排版截图发 AI，让它照着这个风格给你配一套。

---

说到底，这东西就是把"做简历"这件事，从排版工具里解放出来。你只需要操心一件事：**经历说得对不对**。
